PRIVACY POLICY · EFFECTIVE OCTOBER 14, 2026

This policy describes how the Hushborn channel owner uses Google API data through Hushborn YouTube Uploader, a private desktop utility.

Information the utility accesses

With the owner's Google authorization, the utility reads the YouTube channel ID and channel details to confirm the destination. It reads the selected video's title, channel, privacy setting, processing status, and API responses needed to confirm an upload.

It sends the locally selected video, thumbnail, title, description, language, category, audience setting, and synthetic-media disclosure to YouTube. It does not request access to Gmail, contacts, Google Drive, or payment details.

How the information is used

Information is used only to upload and manage the owner's selected videos, set thumbnails, verify the correct channel, check upload status, and prevent duplicate uploads. The utility does not use Google API data for advertising, sale, profiling, or training AI models.

Where information is stored

The utility runs on the owner's computer. Upload plans and local result records contain selected file paths and hashes, video metadata, the channel ID, video ID, and upload progress. They do not contain OAuth access or refresh tokens.

Access tokens are held in process memory. If the owner enables remembered authorization, the refresh token is stored in macOS Keychain, associated with the OAuth client and channel. The desktop OAuth client configuration remains in a local credential file, separate from this public website.

No Google authorization tokens, private videos, or local upload records are published to this website or its public source repository.

Sharing and service providers

The selected media and metadata are sent to Google/YouTube to carry out the upload. The operator does not sell or transfer Google API data to other parties for their own purposes.

This informational website is hosted by GitHub Pages. GitHub may process ordinary technical request information under its privacy statement. The website adds no analytics, advertising scripts, tracking cookies, or upload forms. Google and YouTube process data under the Google Privacy Policy.

Retention, deletion, and revocation

Local media, plans, and result records remain on the owner's computer until the owner deletes them. Remembered refresh credentials remain in macOS Keychain until removed; revoking Google access invalidates that access but does not delete the local Keychain entry.

The owner can revoke access at Google Account permissions, remove the utility's saved credential in macOS Keychain Access, and delete local records. Uploaded videos and thumbnails are retained by YouTube until the owner changes or deletes them through YouTube's controls. Revoking the utility's access does not itself delete a YouTube video.

Google API Limited Use

Hushborn YouTube Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and changes

For privacy questions or deletion requests, contact hushbornestories@gmail.com. This page will be updated if the utility's data practices change; the effective date appears above.
