# Hushborn YouTube Uploader website

Static informational pages for the private Hushborn YouTube Uploader desktop utility.

- `index.html`: application homepage
- `privacy.html`: privacy policy
- `terms.html`: terms of use
- `style.css`: shared styles

Deploy these files with GitHub Pages from the root of the `main` branch. This repository contains no upload executable, Google client credentials, OAuth tokens, unpublished media, or local upload records.

Domain ownership verification can be added using the exact HTML verification file or meta tag supplied by Google Search Console. Do not add credential JSON or OAuth callback URLs to this repository.
